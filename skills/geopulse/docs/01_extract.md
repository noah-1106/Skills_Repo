# GeoPulse 萃取范围界定（阶段一产物）

## C 情境
GEO（生成式引擎优化）是 2026 年内容营销核心新战场（品类搜索 22,000+/月）。
现役工具全为 SaaS 订阅（Profound $250/mo、Scrunch $100/mo、Otterly $29/mo），
自托管/私有部署空白。Noah 的 GEO 业务线（企业落地咨询）需要可携带的生产工具：
交付咨询时带自己的系统，客户数据不出客户环境。

## O 操作（判断标准全部可执行）
1. 监测：对 prompt 集定期问 LLM，记录品牌/竞品在回答中的提及
2. 解析：提及判定 = 品牌别名表在回答文本中的确定性匹配（可测）
3. 指标：可见率 = 提及品牌的 prompt 数 / 总 prompt 数；份额 = 品牌提及 / 全部竞品提及
4. 引擎：可插拔 LLM Provider（OpenAI 兼容协议）；无 key 时 demo 模式（确定性 mock）
5. 频率：手动触发或定时（v1 手动 + API 可编程触发）

## P 产物
自托管 Web 系统：FastAPI 后端 + SQLite + 单页前端（趋势图/竞品矩阵/prompt 明细）。
验收：demo 模式端到端可跑出真实报告；配 key 后可真实接入生产。

## 覆盖 / 不覆盖
覆盖：prompt 管理、监测执行、品牌提及解析、可见率/份额/趋势、竞品对比、报告导出
不覆盖（v1）：自动发布内容、多用户权限、邮件订阅推送、传统 SEO 抓取基线
