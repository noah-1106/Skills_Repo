# 本地 Excel/WPS 显式单元格落位

## 用户必须提供

- 工作簿路径；
- 工作表名；
- 每个截图区域对应的单元格，例如 `gender=C5`、`audience=D5`；
- 图片尺寸策略（默认等比 contain）；
- 是否允许覆盖；默认不允许，默认生成结果副本。

不提供单元格映射、工作表不存在或目标不唯一时，不调用网页截图，直接报任务配置错误。

## 首版能力边界

使用 openpyxl 将 PNG 作为**浮动图片锚定到指定单元格**，设置图片尺寸与必要的行高/列宽。它不是 Microsoft 365 原生“置于单元格中”的图片值。

若用户要求筛选、排序时严格随单元格值移动，或明确要求原生 Place in Cell，首版不承诺；另立 Windows Office/PowerShell/COM 适配器并单独验收。

## 写入安全

1. 只写测试副本或 `outputs/` 下的新结果工作簿；原文件保持不变。
2. 目标已有图片或内容且 `overwrite=false` 时停止。
3. 保存后重新打开结果文件，核对工作表、图片数量、锚点、尺寸和图片关系。
4. manifest 记录源工作簿 hash、结果工作簿 hash、单元格映射和图片 hash。
5. 同一任务重跑默认跳过已交付项，不重复插入图片。
