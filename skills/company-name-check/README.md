# 公司核名 · company-name-check

给一批候选公司名，判断**能不能过工商核验**、**有没有撞上别人的品牌 / 商标**。

解决两个经常被混为一谈的问题：

- 字号核验（市场监管局名称库）——名字能不能注册下来
- 品牌 / IP 冲突（知识产权）——注册下来能不能安心用

两者是两套权利，必须分开判。

---

## 快速开始

```bash
pip install -r requirements.txt
brew install tesseract        # macOS；Linux: apt install tesseract-ocr
```

### 1. 全国通道（免登录，弱初筛）

```bash
python3 scripts/check_national.py 靛穹纪 萤穹纪 --trade 科技 --out national.json
```

### 2. 北京通道（需登录，判别力强）

```bash
python3 scripts/check_beijing.py 蓝穹星汉 蓝穹星曜 --profile /path/to/chrome-profile --trade 科技
```

`--profile` 指向一个**已登录 e 窗通 / 北京市政务服务网**的 Chrome 配置目录。

### 3. 品牌 / 商标冲突扫描

```bash
python3 scripts/brand_scan.py --json beijing_result.json --out brand_scan.json
```

## 两个通道的判别力差异（实测）

| 对照组 | 总局通道 | 北京通道 |
|---|---|---|
| 腾讯 | 0 | 33 |
| 阿里巴巴 | 0 | 11 |
| 蓝宇 | 1 | **209** |

同一个「蓝宇」，两通道差 200 倍。总局开放库收录很窄，它的「0 条」几乎不构成证据；
北京通道才有判别力。

## 判定必须分两列

| 字号 | 字号核验 | 品牌/IP | 综合判定 |
|---|---|---|---|
| 蓝穹星汉 | 0 条 | 无命中（星汉建议再核 41 类） | 可申报 |
| 蓝辰星宇 | 0 条 | 🚩 星宇 → 星宇股份 601799 | 建议回避 |
| 星宇纪 | 3 条 | 🚩 星宇 → 星宇股份 | 已占用 + 品牌冲突 |

只看字号那一列，会把「能注册」误判成「能用」。

---

## 实测出来的坑（都已在脚本里处理）

- 总局接口 token 是**链式**的，每次响应都要用新 token；限流时返回「点击太快了」
- 北京验证码是**算术题**（如 `64+4`），不是 4 位数字——按数字读会一直失败
- 验证码与提交必须在**同一个浏览器上下文**里，session cookie 不落盘
- Chrome 起不来先清 `SingletonLock`
- 19 个名字约 2 分钟，shell 60 秒会超时 → 后台跑 + 轮询日志
- 官方商标检索需 CNIPA 账号，且对高频请求敏感，**不要脚本批量刷商标网**

## 品牌词库

`references/brand-watch.json` 收录有明确权利主体的强品牌词（蓝宇、星宇、星环、蓝鲸、极光等），
命中即标 🚩。只收「有权利人」的词，不收通用形容词。

判定分三档，不一刀切：

| 档位 | 含义 | 动作 |
|---|---|---|
| 🚩 高置信冲突 | 明确权利主体 | 回避或取得授权 |
| ⚠️ 通用词命中 | 星辰、星海、星际这类分散商标 | 按类别检索后再定 |
| 🔐 集团自有 | 权利人是自己体系 | 走内部授权 |

---

## 边界

- 开放库是**字符包含匹配**，0 条 ≠ 工商必然通过（读音近似、字形近似要等「名称自主申报」终判）
- 商标终判必须回官方：`sbj.cnipa.gov.cn` 按第 9 / 35 / 42 类检索，需账号
- 公开搜索引擎只能当线索，不进结论
